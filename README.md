# 🎵 VISA Music - Premium Web Music Streaming Platform

VISA Music is a state-of-the-art, high-performance web music streaming application engineered with **React 18**, **Vite**, **TailwindCSS / Glassmorphism Design Tokens**, and **HTML5 Audio Engine**. Designed to deliver an immersive audio visual experience with dynamic ambient visualizers, real-time lyrics, and personalized database listening insights.

---

## ✨ Features & Highlights

### 🎨 1. Premium Glassmorphic UI & Ambient Aesthetics
- **Sleek Modern Interface**: Built using dark-mode aesthetics (`#07090e`, neon emerald `#10b981`, and deep cyan `#06b6d4`).
- **Dynamic Background Aura**: Real-time ambient backdrop blur generated dynamically from track artwork colors.
- **Studio Expanded Player**: Fullscreen player modal featuring interactive audio wave visualizers (**Radial Spectrum**, **Particle Cloud**, and **Frequency Bars**).

### 🎤 2. Synchronized Studio Lyrics & Multi-Tiered Backup
- **Studio Lyrics Tab**: Clean, beautifully formatted lyric display with verse/hook highlighting.
- **Multi-Provider Fallback**: Seamless fallback search handling synchronized and plain-text lyrics with real-time source attribution badges.
- **Copy & Share**: Single-click clipboard copying for track lyrics.

### 🌍 3. Regional Spotlight & Language Preference Toolbar
- **Instant Language Filters**: One-tap multi-language filtering (Telugu, Hindi, Tamil, English, Punjabi, Malayalam, Kannada, Marathi, Gujarati, Bengali, Bhojpuri).
- **Regional Spotlight**: Multi-tab drawer highlighting top regional Artists, Actors, Albums, and Curated Playlists.

### 📊 4. Database-Driven Listening Insights
- **User Analytics**: Tracks total listening duration and play counts in real-time.
- **Top Highlights**: Displays user's top artist, top actor, top music language, and Top 3 most-listened songs directly inside the profile dashboard.

### 📱 5. 100% Mobile Responsive Architecture
- **Mobile Navigation Dock**: Fixed bottom navigation bar optimized for iOS and Android web interfaces.
- **Touch-Friendly Controls**: Touch gesture swipe sheets, responsive volume popovers, and smooth drawer transitions.

### 🔍 6. Real-Time Smart Search & Autocomplete
- **Instant Categorized Results**: Real-time auto-suggestions across tracks, albums, artists, and playlists.
- **Search History**: Persistent recent search memory with quick clearing.

### 💾 7. Personal Music Library
- **Liked Songs**: Instant heart toggles stored to personal library.
- **Custom Playlists**: Create, manage, and add tracks to user-created playlists with live counts.
- **Recently Played**: Chronological history tracking of listened songs.

---

## 🛠️ Technology Stack

- **Frontend Core**: React 18, Vite 8
- **Styling**: Vanilla CSS Design System + TailwindCSS
- **Icons**: Lucide React
- **Visualizers**: HTML5 Canvas API
- **Audio Engine**: HTML5 Audio API with custom bitrate resolution & device target options

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### 2. Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/amaraneniganesh/VISA.git
cd VISA
npm install
```

### 3. Development Server

Start the local development server with Hot Module Replacement (HMR):

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### 4. Production Build

Build the production bundle:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
